## W008 — Interactive Viewer (COMPLETE)

Production-ready, single-file interactive cross-map viewer at
`publish/interactive_viewer.html`, generated by `src/abacus_svg_pid/build_viewer.py`.
Delivered in PR #557. Five core features:

1. **Bidirectional tag ↔ SVG element highlighting** — select a table row to
   highlight/auto-pan to its SVG marker, and vice versa.
2. **Confidence-based triage workflow** — filter chips, search, sorting,
   Confirm/Defer/Reject decisions persisted to `localStorage`, exportable as
   `triage_decisions.json`.
3. **Export & per-layer controls** — CSV export, current-view SVG export,
   single-layer SVG export.
4. **Side-by-side QCELL vs RFCELL comparison** view.
5. **Design ↔ as-drawn toggle mode** with a confidence-coloured table.

No external dependencies / no build step (self-contained HTML).
Reference: `reports/W008_VIEWER_REPORT.md`.
