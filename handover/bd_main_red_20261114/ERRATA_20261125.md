# Errata, 2026-11-25

These corrections answer the review threads on PR #2752. The bundled census
files in `census/` are left byte-for-byte as captured. They are evidence of
what the tools produced at the time.

## 1. Census rule: green needs a success (`tools/wf_hist.py`)

The old rule counted runs that ended `cancelled`, `skipped` and so on as
evidence of green. Under the corrected rule:

- no success in the window: `EVERRED` if there is any failure, otherwise
  the new class `NO_SUCCESS`
- newest run failed, with some success in the window: `GREEN_TO_RED`
- otherwise: `FLAKY` if there is any failure, else `GREEN`

corrected rule (`R` = failure, `G` = success, `-` = other):
