Operational Analysis — β / γ / α Notation

Greek-letter framework for WCS mass-flow operating windows, turndown, and N+1 redundancy.

§1 — Notation System

SymbolMeaningRangeNotes
βWCS.HP mass flow [g/s]200 – 350β_max = 350 g/s (utility sizing baseline)
γPVPS (WCS.LCC) mass flow [g/s]20 – 50γ_nominal = 50 (10 units × 5 g/s)
αTurndown ratio = γ / γ_max0.4 – 1.0α_min = 0.4 (20 g/s); α_max = 1.0 (50 g/s)
ΣTotal WCS flow [g/s]—Σ = β + γ
β / β_max → fractional notation, e.g. 304 g/s = 0.869·β_max ; 330 g/s = 0.943·β_max
β_WCS.HP = 350 − (50 − γ_actual) ⟺ reservation-based scaling for coldbox compatibility

N+1 boundaries

HP-N+1 Loss of one HP unit → β capped at 2/3·β_max ≈ 233 g/s for 3-unit, or 3/4·β_max for COMBI.

PVPS-N+1 Loss of one of 10 PVPS units → γ_max → 45 g/s; α_max → 0.9.
