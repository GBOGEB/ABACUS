1. Bradley-Terry Probability Model

Definition 1 (Bradley-Terry Model). Given $n$ items with latent strength parameters $\boldsymbol{\theta} = (\theta_1, \theta_2, \ldots, \theta_n)$ where $\theta_i > 0$, the probability that item $i$ is preferred over item $j$ in a pairwise comparison is: $$P(i \succ j \mid \boldsymbol{\theta}) = \frac{\theta_i}{\theta_i + \theta_j}$$ (Eq. 1)

Properties

  • Reciprocity: $P(i \succ j) + P(j \succ i) = 1$
  • Scale invariance: For any $c > 0$, replacing $\theta_i$ with $c\theta_i$ for all $i$ leaves probabilities unchanged
  • Transitivity: If $\theta_i > \theta_j > \theta_k$, then $P(i \succ k) > P(i \succ j)$
  • Identifiability: Due to scale invariance, we impose $\max_i \theta_i = 1$ (or $\sum_i \theta_i = 1$)

In our application, $n = 29$ improvement actions are compared pairwise. Let $n_{ij}$ denote the number of times item $i$ is preferred over $j$ in observed comparisons. The total number of possible pairs is $\binom{29}{2} = 406$.

2. Maximum Likelihood Estimation

Definition 2 (Log-Likelihood). The log-likelihood function for the BT model is: $$\ell(\boldsymbol{\theta}) = \sum_{i \neq j} n_{ij} \log \frac{\theta_i}{\theta_i + \theta_j} = \sum_{i \neq j} n_{ij} \left[\log \theta_i - \log(\theta_i + \theta_j)\right]$$ (Eq. 2)

Score Equations

Taking the partial derivative with respect to $\theta_i$:

$$\frac{\partial \ell}{\partial \theta_i} = \frac{w_i}{\theta_i} - \sum_{j \neq i} \frac{n_{ij} + n_{ji}}{\theta_i + \theta_j} = 0$$

where $w_i = \sum_{j \neq i} n_{ij}$ is the total number of wins for item $i$.

Iterative Solution (Zermelo's Algorithm, 1929)

Algorithm 1: Iterative Proportional Fitting

Initialize: $\theta_i^{(0)} = 1$ for all $i$.
For $t = 0, 1, 2, \ldots$ until convergence:

$$\theta_i^{(t+1)} = \frac{w_i}{\displaystyle\sum_{j \neq i} \frac{n_{ij} + n_{ji}}{\theta_i^{(t)} + \theta_j^{(t)}}}$$ (Eq. 3)

Normalize: $\theta_i^{(t+1)} \leftarrow \theta_i^{(t+1)} / \max_k \theta_k^{(t+1)}$

3. Fisher Information Matrix & Confidence Intervals

Definition 3 (Observed Fisher Information). The $(i,i)$-th element of the observed Fisher information matrix is: $$\mathcal{I}_{ii} = -\frac{\partial^2 \ell}{\partial \theta_i^2} = \frac{w_i}{\theta_i^2} + \sum_{j \neq i} \frac{(n_{ij} + n_{ji}) \cdot \theta_j}{(\theta_i + \theta_j)^2 \cdot \theta_i}$$

At the MLE $\hat{\theta}$, the standard error is:

$$\text{SE}(\hat{\theta}_i) = \frac{1}{\sqrt{\mathcal{I}_{ii}(\hat{\theta})}}$$ (Eq. 4)

Confidence Intervals

By asymptotic normality of the MLE:

$$\hat{\theta}_i \pm z_{\alpha/2} \cdot \text{SE}(\hat{\theta}_i)$$

4. Convergence Analysis

Theorem 1 (Zermelo, 1929; Hunter, 2004)

If the comparison graph is strongly connected (i.e., for every pair $(i,j)$ there exists a sequence of comparisons linking $i$ to $j$), then Zermelo's algorithm converges to the unique MLE $\hat{\boldsymbol{\theta}}$ (up to scaling).

Proof sketch (convergence rate)

The iteration map $T: \theta^{(t)} \mapsto \theta^{(t+1)}$ is a contraction in the Hilbert projective metric on the positive orthant. By Birkhoff's contraction theorem, the convergence rate is geometric:

$$\|\theta^{(t)} - \hat\theta\| \leq C \cdot \rho^t$$

where $\rho \in (0,1)$ depends on the connectivity of the comparison graph. For a complete comparison graph (all $\binom{n}{2}$ pairs observed), $\rho \approx 1 - 2/n$.

$\blacksquare$

Convergence Criterion

We declare convergence when:

$$\|\boldsymbol{\theta}^{(t+1)} - \boldsymbol{\theta}^{(t)}\|_1 = \sum_{i=1}^{n} |\theta_i^{(t+1)} - \theta_i^{(t)}| < \epsilon$$

with $\epsilon = 0.001$ (default). For $n=29$ actions, typical convergence occurs in 10–20 iterations when ≥50% of pairs have been compared.

5. Weighted Priority Score Derivation

Definition 4 (Weighted Priority Score). For action $i$ with severity $S_i \in [1,5]$, impact $I_i \in [1,5]$, and effort $E_i$ (hours): $$P_i = w_1 \cdot \frac{S_i}{5} + w_2 \cdot \frac{I_i}{5} + w_3 \cdot \frac{10 - E_i}{10}$$ (Eq. 5)

Default weights: $w_1 = 0.5$, $w_2 = 0.3$, $w_3 = 0.2$ with constraint $w_1 + w_2 + w_3 = 1$.

Score Range

The priority score $P_i \in [0, 1]$:

  • Maximum: $P = 0.5 \cdot (5/5) + 0.3 \cdot (5/5) + 0.2 \cdot (10/10) = 1.0$ (Sev=5, Impact=5, Effort=0)
  • Minimum: $P = 0.5 \cdot (1/5) + 0.3 \cdot (1/5) + 0.2 \cdot (0/10) = 0.16$ (Sev=1, Impact=1, Effort=10)

6. Sensitivity Analysis

Partial Derivatives of Priority w.r.t. Weights

$$\frac{\partial P_i}{\partial w_1} = \frac{S_i}{5}, \quad \frac{\partial P_i}{\partial w_2} = \frac{I_i}{5}, \quad \frac{\partial P_i}{\partial w_3} = \frac{10 - E_i}{10}$$
Example: For MT-13 (400V Power Analysis): $S=5, I=5, E=4$
$\frac{\partial P}{\partial w_1} = 1.0, \quad \frac{\partial P}{\partial w_2} = 1.0, \quad \frac{\partial P}{\partial w_3} = 0.6$
Interpretation: This action's priority is equally sensitive to severity and impact weight changes, less sensitive to effort weight.

Rank Stability

Two actions $i, j$ swap ranks when:

$$P_i(w_1 + \Delta w_1, w_2, w_3 - \Delta w_1) < P_j(w_1 + \Delta w_1, w_2, w_3 - \Delta w_1)$$

The critical weight shift $\Delta w_1^*$ that causes $i$ and $j$ to swap is:

$$\Delta w_1^* = \frac{P_i - P_j}{\frac{S_j - S_i}{5} - \frac{(10-E_j) - (10-E_i)}{10}}$$

7. Numerical Examples

Example: 3-Action BT Computation

Consider actions A, B, C with observed comparisons: A beats B (1×), A beats C (1×), B beats C (1×).

Iteration 0: $\theta = (1, 1, 1)$

Iteration 1:
$\theta_A = \frac{w_A}{\frac{n_{AB}+n_{BA}}{\theta_A+\theta_B} + \frac{n_{AC}+n_{CA}}{\theta_A+\theta_C}} = \frac{2}{\frac{1}{2} + \frac{1}{2}} = 2.0$
$\theta_B = \frac{1}{\frac{1}{2} + \frac{1}{2}} = 1.0$
$\theta_C = \frac{0}{\frac{1}{2} + \frac{1}{2}} \rightarrow 0.01$ (clamped)

Normalize: $\theta = (1.000, 0.500, 0.005)$

Final (converged): $\theta = (1.000, 0.500, 0.010)$
Ranking: A > B > C ✓
