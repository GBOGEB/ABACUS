Bug Tracker

BUG-004 FIXED v0.4.4

bt-ranking.html not rendering

Root cause: Multiple issues — (1) no auto-seeding on first visit left all θ=1.0, (2) converged flag set true with 0 comparisons, (3) Float64Array.flat() not available in all browsers, (4) Plotly render error in renderPlots() prevented renderYAML() from executing.

Fix: Auto-seed from severity×impact/effort on first load, guard convergence flag, replace .flat() with Array.from(), add try-catch around Plotly calls, reorder render calls (YAML before Plotly).

BUG-005 OPEN

Mobile chart overflow on Safari

Plotly charts overflow their container on Safari iOS below 780px. Related to BUG-002. Needs CSS overflow:hidden on .card containers + Plotly responsive:true config.

BUG-006 OPEN

Dark theme missing on 6 new views

bt-ranking, qa-interactive, vendor-kaeser, artifact-index, changelog-dev, stats-proofs have incomplete dark theme support. Custom CSS variables needed for chart-specific elements.

BUG-007 OPEN

Navigation breadcrumbs missing on some views

graphs.html, tables.html, operations.html missing breadcrumb navigation. Template should be applied consistently.

BUG-008 MITIGATED

localStorage persistence in Safari private mode

Safari private browsing throws on localStorage.setItem. Mitigated with try-catch in common.js theme/font persistence. BT ranking data also wrapped.
