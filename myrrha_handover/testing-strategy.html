Automated Test Prioritization

  1. common.js → Test navigation, breadcrumbs, theme toggle, version display on ALL 25 consuming views
  2. style.css → Visual regression tests on 5 representative views (mobile + desktop): index, bt-ranking, vendor-kaeser, tables, thermo-analysis
  3. data.json → Schema validation (JSON Schema), value range checks, consistency across 14 consuming views
  4. render_all.py → Snapshot tests: input master sources → expected output HTML diffs
  5. index.html → Link checking (all 30 outgoing), card navigation, search functionality
  6. bt-ranking.html → BT algorithm unit tests, MLE convergence, CI calculation, Plotly chart rendering
  7. action-tracker.html → Filter/sort, data binding to 29 actions, severity badge rendering
