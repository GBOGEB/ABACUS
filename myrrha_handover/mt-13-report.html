1Executive Summary

Conclusion: ✅ 400V 3-phase AC supply is FEASIBLE for MYRRHA WCS at 350 g/s baseline operation.

The site electrical load reaches approximately 1,437 kW under continuous operation (rounded to 1,500 kW with contingency). A 2,000 kVA transformer provides adequate capacity with 20% margin. Harmonic filtering, power factor correction, and emergency UPS are required to meet IEEE 519 standards and minimise grid disturbance. Total electrical infrastructure cost: €604k.

⚠ Critical constraint: Maximum VFD frequency limit is 72 Hz at 400V. This directly impacts Kaeser FSD compressor selection and PVPS unit specifications. Vendor confirmation required before purchase.

4.3 Harmonic Mitigation Strategies

Option A: Active Harmonic Filter (Recommended)

Uses IGBTs to inject 180° out-of-phase currents, cancelling harmonics in real-time.

Data Table
ProsCompact · Dynamic (adapts to load) · Improves PF to >0.95 · <0.5% THD achievable
ConsHigher cost (~€65–80k) · More complex controls · Requires trained technician
SizingReactive power: 1,215 kW × 0.4 = 486 kVAR

Option B: Passive LC Filter (Cost-Conscious)

Inductors and capacitors tuned to trap 5th, 7th, 11th harmonic frequencies.

Data Table
ProsLower cost (~€40–50k) · No active controls · Reliable, long-life
ConsFixed tuning (less flexible) · ~3–5% residual THD · Requires tuning to specific load profile
SizingTraps 5th, 7th, 11th, 13th harmonics; 486 kVAR total

Option C: Premium VFDs (Active Front-End)

Kaeser COMBI units with AFE (Active Front-End) topologies generate <3% THD inherently.

Data Table
ProsNo separate filter needed · Best EMC profile · Future-proof
ConsHigher VFD cost (~€8–12k premium per unit) · Adds ~€100k to CAPEX if applied to all VFDs
DecisionSuitable for Kaeser 3× units; PVPS may use standard VFDs + passive filter

4.4 Recommendation

Proceed with Option A: Active Harmonic Filter

Rationale: Provides best performance (THD <2%), supports dynamic load swings (PVPS on/off), and enables future flexibility. Cost (~€70k including installation) is recovered through avoided utility power factor surcharges over project lifetime.

Alternatives: If budget-constrained, hybrid approach: premium VFDs on Kaeser units + passive filter on PVPS.

5.2 Reactive Power Requirement

To improve power factor from 0.90 to 0.95:

Q_correction = P × (tan(φ₁) − tan(φ₂))
Q_correction = 1,500 kW × (tan(acos(0.90)) − tan(acos(0.95)))
Q_correction = 1,500 × (0.484 − 0.329)
Q_correction ≈ 233 kVAR

Conservative estimate: use 200 kVAR (accounts for existing VFD improvements)
