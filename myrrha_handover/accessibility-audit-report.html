  • plotScatter: "Scatter plot showing BT scores across artifacts"

  • plotRankDist: "Distribution of artifact ranks"
  • plotConfidence: "Confidence intervals for BT scores"

  • plotRanks: "Ranking visualisation"
  • plotConverge: "Convergence plot showing algorithm iterations"
  • plotCategory: "Category analysis visualisation"

Button Labels

All interactive buttons now have descriptive aria-label attributes generated from context:

  • Dimension filters: "Filter by overall", "Filter by type", etc.
  • Sort controls: "Sort by rank total", "Sort by BT overall", etc.
  • Export buttons: "Export data as JSON", "Export data as CSV", etc.

Remaining Items (Non-blocking)

  • Plotly chart keyboard interaction: Plotly.js charts have limited keyboard support natively. Consider adding tabular data alternatives for screen readers in future versions.
