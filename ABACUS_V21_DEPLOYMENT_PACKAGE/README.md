## 🎯 Overview

ABACUS v2.1 is a comprehensive session tracking and conversation analysis system with full deployment automation.

## 🚀 Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run session analyzer
python abacus_v21_session_tuple_analyzer.py
```

## 📦 Core Components

- **Session Analysis**: `abacus_v21_session_tuple_analyzer.py`
- **Deployment**: `abacus_v21_production_deployment.py`
- **Monitoring**: `abacus_v21_monitoring_integration.py`
- **Security**: `abacus_v21_security_hardening.py`

## 🐳 Docker Deployment

```bash
docker build -t abacus-v21:latest .
docker-compose up -d
```
