Math + empirical proof contract (thresholds are pre-fit heuristics)

PCA: for X ∈ ℝ^(n×p), standardize finite nonconstant columns and compute C = ZᵀZ/(n−1); eigenpairs Cvₖ=λₖvₖ, EVRₖ=λₖ/Σλ. Preliminary sample screen n ≥ max(30,5p) does not prove independent units, stability, eigengaps, or causality. Same-run jobs are clustered, not independent.

Bradley–Terry: Pr(i > j) = exp(θᵢ)/(exp(θᵢ)+exp(θⱼ)). The producer needs exact-SHA, identical test-contract digest, distinct trials and real winner/loser outcomes; ≥30 independent pairs and a strongly connected win graph are only eligibility requirements. No model uncertainty or promotion until separately established.

Testing architecture / mission taxonomy

CONFIGURED ≠ EXECUTED

Evidence maturity ladder

1. CONFIGUREDWorkflow YAML, matrix definition, static policies. No execution claimed.
2. EXECUTEDGitHub run, attempt and job receipt on exact SHA; may have RED/cancelled outcomes.
3. SOURCE-BOUNDSHA + run/job + matched test/JUnit/coverage/scanner config + artifact hash.
4. ACCEPTEDIndependent causal evidence, security/review/governance gates; never inferred from workflow green.

This ladder classifies proof quality, not a chronological execution phase or named ownership. Every layer can contain multiple owners.
