# CODE PURPLE Dashboard V3.2 - architecture visual semantics

This release is an additive visualization correction for the source-bound V3.1 dashboard. It does not replace the native collector, modify CI gates, promote analysis into accepted engineering proof, or claim successful governance admission.

## Architecture legend

| Glyph or treatment | Meaning | It does not mean |
|---|---|---|
| Neutral process card | Activity or phase | Green/success or global owner |
| P1-P8 | Ordered process phase | A completed task |
| Role: ... | Contractual actor/function | Authenticated worker assignment |
| Purple border plus decision diamond | Decision/question type | Approved Yes and No outcomes |
| Green conditional Yes route | Eligible path if all gates have proved PASS | Current merge authority |
| Red No / Hold route | Admission stopped, requires another measured pulse | A single root automatically confirmed |
| Solid neutral arrow | Acyclic forward dependency | Feedback or causal proof |
| Dashed amber left/backwards signal | Corrective feedback, new RCA pulse | Same-pulse DAG edge |
| Double cyan forward signal | Risk-informed feedforward / focused test preflight | A live or calibrated predictive worker |

**Source roles are distributed.** There may be one canonical accountable repair owner per confirmed causal root; there is no unique global controller or owner inferred from purple fill. Actual named worker identity remains UNKNOWN until an authenticated receipt exists.

## Graph semantics

`forward_v32.mmd` is an acyclic admission DAG: native evidence to diagnosis/repair, native verification, independent gate, No HOLD or conditional Yes -> authorized integration -> integrated-main verification. A No path does not connect directly to Yes. Native CI, independent reviewer and branch-policy checks form a conjunctive gate. Importantly, the process does not automatically merge.

`control_overlay_v32.mmd` is a **separate non-DAG control signal graph**. Feedback sends observed later-pulse RED/recurrence back to new counterfactual RCA; feedforward routes earlier-risk evidence into preflight test selection. These are architectural proposals, not authenticated live worker actions.
