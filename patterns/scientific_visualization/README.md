# Scientific Visualization Schema

Canonical schema artifacts for ABACUS scientific visualization governance payloads.

## Canonical files

- `schema.yaml` — canonical editable schema source.
- `schema.json` — JSON mirror of `schema.yaml` for strict JSON consumers.
- `validation_rules.yaml` — rule-level validation bindings for runtime checks.
- `lineage.yaml` — governance lineage bindings for runtime evidence.

All schema consumers must resolve these files from `patterns/scientific_visualization/`.
