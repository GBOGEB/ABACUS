# AD_07 QPLANT Cybersecurity Policy Framework

## Summary

This PR introduces the project-specific cybersecurity baseline for QPLANT.

The baseline derives from the SCK CEN Cybersecurity Framework and maps applicable controls into a procurement-oriented Cybersecurity Policy Framework (CPF).

## Deliverables

- AD_07 QPLANT CPF
- CPF_01 through CPF_18
- QPS-CYBER-001 through QPS-CYBER-018
- Supplier Control Response Matrix (Important + Essential only)
- RTM-322 traceability
- Graph Compendium
- Dashboard reporting
