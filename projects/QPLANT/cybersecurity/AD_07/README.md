# AD_07 - QPLANT Cybersecurity Policy Framework (CPF)

This folder promotes the project-specific QPS cybersecurity baseline as the AD_07 candidate sharing package for QPLANT.

## Status

Review baseline: `v4-review`

## Contractual anchor

- Contract reference: RTM-322
- Source basis: SCK CEN Cybersecurity Framework / CyFun basis
- Project baseline: 18 QPS-specific CPF controls
- Supplier response instrument: Supplier Control Response Matrix (SCRM)

## Numbering model

| Layer | Identifier example | Purpose |
|---|---|---|
| Enterprise framework | `ID.AM-03.2` | Source traceability |
| Project CPF | `CPF_03` | AD_07 project control reference |
| QPS contract | `QPS-CYBER-003` | Tender clarification, offer review, SCRM and V&V |

## Supplier response rule

Applicants shall complete the SCRM for **Important** and **Essential** controls only.

**Basic** controls remain baseline expectations unless the Applicant proposes a deviation.

## Primary QPS baseline

The QPS project priority set is the 18-control extract:

- `CPF_01` to `CPF_18`
- `QPS-CYBER-001` to `QPS-CYBER-018`

The full 218-row enterprise framework remains the upstream SSOT and traceability layer, but is not the primary applicant-facing AD_07 package.
