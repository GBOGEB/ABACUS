🚀 DEPLOYMENT PHASES - EXECUTION ROADMAP
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│ PHASE 1: Prerequisites & Setup (5-10 min)                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ ☐ Install Azure CLI                                                         │
│   winget install -e --id Microsoft.AzureCLI                                 │
│                                                                              │
│ ☐ Login to Azure                                                            │
│   az login                                                                   │
│                                                                              │
│ ☐ Set subscription                                                          │
│   az account set --subscription "YOUR_SUBSCRIPTION"                         │
│                                                                              │
│ ☐ Verify Docker Desktop is running                                          │
│   docker --version                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PHASE 2: Azure Infrastructure (10-15 min)                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ ☐ Create Resource Group                                                     │
│   az group create --name abacus-rg --location westeurope                    │
│                                                                              │
│ ☐ Create Azure Container Registry (ACR)                                     │
│   az acr create --resource-group abacus-rg --name abacusregistry --sku Basic│
│                                                                              │
│ ☐ Enable admin access                                                       │
│   az acr update --name abacusregistry --admin-enabled true                  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PHASE 3: Container Build & Registry (15-20 min)                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ ☐ Navigate to deployment package                                            │
│   cd ABACUS_V21_DEPLOYMENT_PACKAGE                                          │
│                                                                              │
│ ☐ Build and push image to ACR                                               │
│   az acr build --registry abacusregistry --image abacus:v2.1 .              │
│                                                                              │
│ ☐ Verify image                                                              │
│   az acr repository list --name abacusregistry                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PHASE 4: Application Deployment (10-15 min)                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│ ☐ Create Container Apps Environment                                         │
│   az containerapp env create --name abacus-env --resource-group abacus-rg   │
│                                                                              │
│ ☐ Deploy Container App                                                      │
│   az containerapp create --name abacus-app --resource-group abacus-rg \     │
│     --environment abacus-env --image abacusregistry.azurecr.io/abacus:v2.1 \│
│     --target-port 8000 --ingress external --cpu 1.0 --memory 2.0Gi          │
│                                                                              │
│ ☐ Get application URL                                                       │
│   az containerapp show --name abacus-app --resource-group abacus-rg \       │
│     --query properties.configuration.ingress.fqdn                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PHASE 5: Verification & Testing (5-10 min)                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ ☐ Check application status                                                  │
│   az containerapp show --name abacus-app --resource-group abacus-rg         │
│                                                                              │
│ ☐ View logs                                                                 │
│   az containerapp logs show --name abacus-app --resource-group abacus-rg    │
│                                                                              │
│ ☐ Test health endpoint                                                      │
│   curl https://YOUR_APP_URL/health                                          │
│                                                                              │
│ ☐ Test API documentation                                                    │
│   Open: https://YOUR_APP_URL/docs                                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PHASE 6: Monitoring Setup (Optional, 10-15 min)                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ ☐ Create Application Insights                                               │
│   az monitor app-insights component create --app abacus-insights \          │
│     --location westeurope --resource-group abacus-rg                        │
│                                                                              │
│ ☐ Configure monitoring                                                      │
│   az containerapp update --name abacus-app --resource-group abacus-rg \     │
│     --set-env-vars "APPLICATIONINSIGHTS_CONNECTION_STRING=..."              │
│                                                                              │
│ ☐ Access dashboards                                                         │

🔧 TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Problem: Azure CLI not found
Solution: winget install -e --id Microsoft.AzureCLI
         Restart PowerShell after installation

Problem: ACR name already taken
Solution: Use unique name: abacusregistry$(Get-Random -Maximum 9999)

Problem: Container build fails
Solution: Check Dockerfile syntax
         Verify all files in ABACUS_V21_DEPLOYMENT_PACKAGE/
         Check logs: az acr task logs --registry abacusregistry

Problem: Container app won't start
Solution: Check logs: az containerapp logs show --name abacus-app --resource-group abacus-rg
         Verify image exists: az acr repository list --name abacusregistry
         Check resource limits (CPU/Memory)

Problem: Can't access application URL
Solution: Verify ingress: az containerapp ingress show --name abacus-app --resource-group abacus-rg
         Check replicas: az containerapp replica list --name abacus-app --resource-group abacus-rg
         Wait 2-3 minutes for DNS propagation

Problem: Authentication errors
Solution: Re-login: az login
         Verify subscription: az account show
         Re-login to ACR: az acr login --name abacusregistry
