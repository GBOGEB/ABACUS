🧊 Cryogenic Analysis Dashboard

Interactive visualization of helium system analysis, heat load calculations, and cooldown simulations for the QPLANT cryoplant.

Overview

The Cryo Dashboard (v0.3.0) provides real-time interactive visualization of cryogenic engineering data processed through the DMAIC pipeline. It covers helium distribution networks, thermal load profiles, and cooldown trajectory modeling.

🚀 Quick Start

  1. Open the Cryo Dashboard v0.3.0 in your browser.
  2. Use the sidebar tabs to navigate between Heat Load, Cooldown, and Distribution views.
  3. Hover over chart elements for detailed tooltips; click to drill down.
  4. Export data via the Export CSV button in each panel.

📊 Dashboard Capabilities

Heat Load Analysis

Static + dynamic heat load breakdown by component. Supports what-if scenarios for insulation upgrades.

Ready

Cooldown Simulation

Time-temperature trajectory modeling from 300 K → 4.5 K with configurable flow rates and boundary conditions.

Ready

Helium Distribution

P&ID-linked helium flow network visualization with pressure drop and mass flow calculations.

Ready

DMAIC Integration

Each analysis maps to DMAIC phases: Define (scope), Measure (data), Analyze (model), Improve (optimize), Control (validate).

🔧 Troubleshooting

IssueSolution
Dashboard shows blank chartsEnsure data files are in cryo_dashboard_v0_3_0/data/. Check browser console for 404 errors.
Slow renderingReduce dataset size or enable progressive loading in settings panel.
Export failsCheck browser pop-up blocker settings. CSV export uses Blob API.
Missing thermophysical dataInstall CoolProp: pip install CoolProp or use bundled lookup tables.
