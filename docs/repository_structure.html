🔁 Data Flow

Code change
(push to main)
→
CI workflows
ci.yml / book-build.yml
→
DMAIC metrics
dmaic-commit-metrics.yml
→
docs/api/*.json
JSON artifacts
→
GitHub Pages
deploy-docs.yml
→
Live dashboards
index, metrics, status

Every push to main runs the CI suite, recalculates the DMAIC quality score, writes JSON + chart artefacts into docs/api/, triggers deploy-docs.yml, and updates the live launcher. dashboard-health.yml validates the result the following morning.
