What the bindings found

  • RTM-292 sets a nominal and a minimum pressure only. The 1.30 bar ASSUM-PLIMIT ceiling comes from the He_line_safety sheet, not from RTM-292.
  • 112 g/s is not an RTM-292 use case. In the repository it appears only as the HP compressor 72 Hz maximum reference, so its pedigree as MDOT_IN_PRE_HP_MAX stays open (gap 2).
  • Rev 146 gives no number for the Thermal Shield temperature limit. The closest data is Table 7 TS-SB: line D ~40 K ±5, line E ~60 K ±10 (gap 9, owner question).

Run the checks

From the ABACUS checkout root (Python 3.11+, pytest, pyyaml):

python -m pytest -q tests/test_ssot_tables_contract.py tests/test_rtm292_contract.py tests/test_loop_transient.py
python -m models.qps_line_s.loop_transient

Generated matrices (generated/) are not tracked; CI rebuilds them in qps-line-s-validation.
