# Glossary

Each entry gives the term, its type and its definition.

- **ABACUS** (repository): Domain repository for architecture, modelling,
  traceability, and engineering system packages.
- **CODEX** (repository): Reusable code and workflow pattern repository.
- **Line S** (system line): Safety Valves GHe return line used to collect helium
  from safety valves for recovery where applicable.
- **LOOP** (abnormal event): Loss of utility event; here used for loss of
  electrical supply and associated fallback states.
- **QPS** (system): Cryoplant or cryogenic supply system context for helium
  recovery and protection functions.
- **QCELL** (subsystem): Cryogenic cell composed of one cryomodule and its
  cryogenic valve box.
- **QVE** (subsystem): End box at the end of the cryogenic manifold.
- **QRB** (subsystem): Refrigerator cold box.
- **RTM-260** (requirement): Requirement limiting helium loss during abnormal
  events.
- **RTM-261** (requirement): Requirement for the system to cope with helium
  return flow through Line S during normal and abnormal operation.
- **RTM-292** (requirement): QRB.S flow conditions (Addendum II rev 146, p. 68):
  nominal return pressure 1.1 bar +/- 5 mbar, minimum allowable pressure 1.05
  bar, and return-flow use cases of 0.1, 100 (spikes to 150) and 200 g/s. It
  sets no maximum pressure.
- **RTM-293** (requirement): QPS design and operating sequences shall not let
  the WPS.S pressure drop below the RTM-292 minimum (rev 146, p. 69).
- **RTM-061** (requirement): Failure classes A, B and C for the availability and
  reliability assessment (rev 146, p. 38). Classes A and B carry the Thermal
  Shield temperature limit bullets mirrored as REQ-130 and REQ-131.
- **Bounded pressure buffer** (concept): Temporary Line S accumulation accepted
  only if pressure remains below all applicable limits and no credited no-loss
  case vents helium.
- **Design-point heat load** (parameter): 8700 W thermal-shield heat-load point
  equal to true baseline multiplied by 1.44 in the corrected sensitivity
  lineage.
- **True nominal baseline heat load** (parameter): 6041.7 W, calculated as 8700
  divided by 1.44.
- **Uncertainty-only heat load** (parameter): 7250 W, calculated as true nominal
  baseline multiplied by 1.2, equivalently 8700 multiplied by 100 divided by
  120.
