## Engineering deductions

1. **RTM-462 is a fabrication-quality negotiation item, not merely paperwork.** Supplier code practice can be proposed as an equivalence case, but it cannot silently lower ISO 5817 Level B / defect / cryogenic-verification expectations.
2. **RTM-481 is a useful cost-avoidance/equivalence opportunity.** Repeating a valid calibration at site may add little value if traceability and integrity are preserved; the Owner can define objective triggers for recalibration instead of requiring repetition by default.
3. **RTM-515/516/520 form one SAT coverage problem.** A single controlled verification matrix should map WCS component tests, QRB component tests, integrated modes/transitions and performance metrics to Commissioning/FAT/SAT evidence without duplicate testing and without deleting required coverage.
4. **RTM-516 is particularly suitable for evidence reuse rather than scope deletion.** Commissioning evidence can satisfy prerequisite/unit-level checks while SAT demonstrates integrated system behaviour, provided lineage and acceptance criteria are explicit.
