The three lenses (why tabs 3–5 exist)

Every RTM/OFFER item in this project can be read through three independent lenses, and this dashboard's own navigation is built around them rather than around file names:

Ranking
the score itself — Weighted S, Sum vs. Average
Importance
the tier/gate flag — T0/T1/T2/T3
Relevance
context — Domain, Cluster, Phase, Codes & Standards

The DMAIC report's central finding is that these three lenses are independent of each other — a high Weighted S item is not necessarily T0, and a T0 item is not necessarily high-scoring (see the Importance tab). Reading only one lens at a time is the single most common way to mis-prioritize this dataset.

3. Ranking — the score itself

"Ranking" in this project means Weighted S: the 7-dimension weighted sum (L/R/P/F/Q/LC/C) computed per RTM/OFFER item. Two aggregate readings of it diverge on purpose — this section exists so that divergence reads as expected, not as a bug.

Read together, for a presenter: Sum answers "where is the volume/total exposure" — Subsystems wins because it has 202 items, not because each item is unusually high-stakes. Average answers "which items are individually highest-stakes" — Commissioning wins there with just 4 items, every one scoring high. A domain scoring high on one and mid-pack on the other is the two lenses doing their separate jobs, not a data problem. Full numbers and the PCA structure behind this: DMAIC_BT_TECHNICAL_REPORT.html §2.1–2.2.

4. Importance — tier and gate status

"Importance" means Tier: T0 Gate / T1 Primary / T2 Secondary / T3 Contextual. This is a categorical, hand-flagged compliance status (gate = Yes/No) — not derived from the Weighted S score. Confirmed with live data this round.

TiernMin Weighted SMax Weighted SAvg Weighted S
T0 Gate4320.0062.6731.60
T1 Primary15637.3376.6747.46
T2 Secondary24424.0037.3330.24
T3 Contextual2790.0024.0019.81
Read this one carefully: T0 Gate is not the top-scoring tier — T1 Primary has both the highest average (47.46) and the single highest score (76.67) in the entire RTM. T0's own score range (20.00–62.67) overlaps T2's, and 19 of the 43 T0 items sit at exactly 20.00, the population floor. T0 should be read as "must not fail," not "ranks highest." A reviewer sorting by Weighted S alone will systematically under-prioritize several T0 items — sort or filter by Tier for compliance triage, by Weighted S for intensity triage, and don't assume one implies the other. Full writeup: DMAIC_BT_TECHNICAL_REPORT.html §3.4.

Where to browse it live

Workbook: RTM_REVIEW_QUEUE (all T0/T1 RTMs plus deliverable-heavy items), COMPLIANCE_LEGEND (formal Tier/Review-flag definitions). Navigator: Review Queue tab's Tier colour key and filter dropdown.

5. Relevance — context: domain, cluster, phase, codes & standards

"Relevance" means the contextual facets that group items without ranking them: which technical Domain an item belongs to, which Cluster (C1–C8) it maps to, which project Phase (L0–L8) it applies in, and which Code/Standard it cites. None of these are ordinal — a domain isn't "better" than another, it's just a different lens to filter or group by.
