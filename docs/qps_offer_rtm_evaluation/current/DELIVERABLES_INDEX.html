2. How they relate to each other

Read together: the FULL workbook is the only place data is ever entered or changed. The LITE workbook and the HTML Navigator are both generated from FULL — never edited independently, and both regenerate cleanly any time FULL changes (LITE via a Python build script that drops internal-only sheets; the Navigator via a JSON data export spliced into a reusable HTML template — this round's PCA_ANALYSIS sheet and the Navigator's new "PCA / Structure" tab are generated from the same two source computations, compute_pca.py and compute_weight_scenario4.py, so they can't drift from each other either). The Taxonomy PDF export is a third downstream artefact of the same workbook, rebuilt from the Navigator's own JSON data export. The two PowerPoint decks are separate lineages with their own narrative content, not auto-generated from the workbook, which is why they're flagged "watch" above — they need a human to carry forward whatever changed, not just a script re-run; the BT deck specifically has NOT yet absorbed this round's PCA/weight-scenario-4 findings (open backlog item 28d). The two dashboards (Master Developer, KPI) are also hand-built HTML rather than a single push-button script the way the Navigator is — both are now linked from this page for the first time; both had genuinely stale in-page version strips found during this round's own QA pass and both were corrected to v24/v22/v12 (the KPI dashboard via its real build scripts, after fixing two real bugs in them; the Master Developer Dashboard via a disclosed hand-patch, since it has no regeneration script yet) — see their cards above for the full detail.
