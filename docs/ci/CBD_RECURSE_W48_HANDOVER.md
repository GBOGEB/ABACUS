## Reproduce local testflight

From ABACUS repository root with Python 3.11+, `PyYAML` and Node 20+ available:

```bash
bash scripts/run_cbd_recurse_w48_local.sh
```

To compile an independently exported observation corpus (it still requires external verification of purported native receipts):

```bash
python3 scripts/cbd_recurse_fanout_w48.py \
  --input INPUT_EXPORTED_OBSERVATIONS.json \
  --manifest ci/cbd_recurse_local_w48.yaml \
  --output NEW_STRUCTURAL_OUTPUT.json
node scripts/cbd_recurse_public_w48.mjs \
  NEW_STRUCTURAL_OUTPUT.json NEW_PUBLIC_PROJECTION.json
```

Outputs are created with fail-if-existing semantics, deterministically sorted, and must be attached to an exact source SHA, run/job/attempt, trusted native artifact hash and independent reviewer before any promotion. Multiple git branches can appear in one graph; coverage comparisons are only valid when scoped source blob, coverage tool/cell and eligible denominators match.
