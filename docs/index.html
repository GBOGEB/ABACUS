📦 Apply This Methodology to Your Repo

The toolkit and playbook are repo-agnostic. Use them to bring any of your sister repositories to ABACUS-level quality in 2–3 weeks.

1Clone the toolkit

Copy repo_analysis_toolkit/ into your repo (or clone ABACUS and copy out).

2Install dependencies

pip install -r repo_analysis_toolkit/requirements.txt

3Run baseline audit

python repo_analysis_toolkit/analyze_repo.py --repo . → produces baseline.json

4Classify artifacts

python repo_analysis_toolkit/classify_artifacts.py --repo . → labels Active / Archived / Stale / Redundant / Corrupted

5Follow Quick Start

Open REPO_CLEANUP_QUICK_START.md and execute the 3-week plan day-by-day.

6Validate & iterate

python repo_analysis_toolkit/validate_cleanup.py --repo . → target ≥75/100 for exit
