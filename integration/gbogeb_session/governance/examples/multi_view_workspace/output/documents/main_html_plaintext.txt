PHYSICS ENGINE (Python)
-----------------------
HeliumPropertyEngine:
  enthalpy(T) → J/g via NIST 6th-order polynomial
  density(T) → kg/m³ via NIST polynomial
  viscosity(T) → μPa·s (He-I only, T > λ)
  phase(T) → "He-II" if T < 2.1768 K else "He-I"

verify_mass_balance(Q_static, Q_dynamic, h_supply, h_return, m_dot_design, SF=1.5):
  m_dot = (Q_static + Q_dynamic) / (h_return - h_supply)
  deviation = |m_dot × SF - m_dot_design| / m_dot_design × 100
  PASS if deviation ≤ 5%

KEY FORMULAS
------------
Mass balance:    ṁ = (Q_static + Q_dynamic) / Δh
Enthalpy diff:   Δh = h_return - h_supply = 26.14 - 2.56 = 23.58 J/g
Design flow:     ṁ_design = ṁ_calc × SF = 3.066 × 1.5 = 4.599 g/s
Polynomial:      h(T) = Σ(n=0..6) aₙ·Tⁿ
