Clock-chain narrative

Measure run creation → job created → job started → job completed with explicit clock sources. Queue wait is job.started_at - job.created_at only when both trustworthy native timestamps exist. run.created_at - run.started_at is not a substitute. A locally instrumented process uses a monotonic timer. The sum of concurrent job runtimes is not total elapsed wall clock.

The next cache MIP should use paired cold/warm cohorts and preserve a locked dependency/wheel manifest, test selection, runner image and exact source SHA. Score the saved time and confidence after the experiment, not from an anecdotal 300-second comparison.
