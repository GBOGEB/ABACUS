# Status, completion and result reports (moved from the repository root)

<!-- markdownlint-disable MD013 -->

Point-in-time status summaries, completion reports and result notes without a
version in their name, moved out of the repository root in wave W3 of the
[root refactor](../../docs/repo-structure/ROOT_REFACTOR_PLAN.md). Contents and
file names are unchanged; old → new paths are in
[`ROOT_RELOCATION_MAP.csv`](../ROOT_RELOCATION_MAP.csv), and the
[repository map](../../docs/repo-structure/index.html) searches every former root file.

These are history, not current status. Reports whose name carries a version
(V2.1, V2.2, V2.3, V3.x, v4.4) go to the matching version folder in
[`docs_versioned/`](../) instead.
